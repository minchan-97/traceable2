# 몰랑이 반사실적 분기 실험

검토일: 2026-10-10. 입력: 69(1), 73(1), 77, 81(1) 피클.
선택 도구: 실행률 축 추가 Traceable. 사고 엔진: molang_v14_supabase 32(2).zip의 thought_structure.py 및 llm_bridge.py.

## 결론
81번의 갈림길 기록 149건에 대해 기록된 원래 선택을 재생하고, 한 분기만 다른 후보로 강제했다.
원래 경로 재생 일치 149/149, 개입 후 경로 변화 149/149, 동일 피드백 적용 후 전이 가중치 변화 149/149.
빈 node_map에서는 최종 생성 프롬프트 변화 0/149. 실제 노드 사전을 연결한 실험 조건에서는 149/149 변화.
이는 로컬 경로 및 학습 상태에 대한 인과적 개입 증거이며, 답변 품질이나 실제 발화 변화의 증거는 아니다.
LLM API를 호출하지 않았다. Spy 클라이언트로 최종 전달 프롬프트만 캡처했다.

## 사례
inference_1에서 grown_inference_1 대신 inference_2를 강제했다.
피드백 +0.5를 동일하게 적용하면 grown_inference_1의 다음 가중치는 원래 선택에서 0.639953, 대안 선택에서 0.610265였다.
inference_2의 다음 가중치는 각각 0.132337, 0.162026이었다.

## 재현 범위와 결함
81번 기록 386건 중 at_probs가 있는 것은 151건이고, seed는 모두 None이다.
원래 replay()는 LLM 선택을 재실행하지 않고 seed 없는 경우 Random(0)으로 확률 추첨한다.
151건 중 same=True 117건이나 이는 역사적 LLM 선택을 재현했다는 증거가 아니다.
반환 path에는 연속 노드가 중복되고, 분기가 달라지면 대안 경로의 끝까지 실행하지 않는다.
반면 본 개입 실험은 기록 선택을 강제 재생하고 같은 코드의 traverse/learn을 실행했다.
당시 at_probs는 소수점 4자리로 반올림돼 있어 가중치 변화 수치는 근사 복원 결과다.
오프패스 구조는 저장 시점 그래프를 사용하며 과거 전체 그래프 버전은 없다.

## Traceable 점수의 해석
현재 어댑터는 replayable을 설정하지 않아 replay 점수가 모두 0이다. 실험으로 검증된 실패율이 아니다.
learning은 전후 학습 효과가 아니라 현재 분기 가중치의 최대-최소 차이를 센다.
evidence는 트리에 기억이 존재하는지이며 개별 답변에 그 기억이 실제 사용됐는지는 아니다.
source는 conversation 기본값과 source_trust 대체값을 인정하므로 원본 출처 완전성 100%를 뜻하지 않는다.
origin은 단어 및 앞 두 글자 겹침이며 인과적 귀속 지표가 아니다.
continuity는 strength >= .8인 동일 사실 문장의 유지율이다. 개체 정체성 전체의 동일성은 아니다.
execution은 계획 ID와 검증된 실행 기록이 없어 미측정이다.
