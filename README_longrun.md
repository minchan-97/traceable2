# 장기 안정성 관찰 (v4)

질문: 몰랑이가 **목적을 스스로 바꾸면서도 반복·정체·퇴행 없이 오래 유지되는가?**

앱의 **"장기 안정성 관찰"** 탭에서 봅니다. 성장 기록 피클(.pkl)을 여러 개 올리면 시점별로 비교합니다.
모델·API 키·Supabase 접속은 필요 없고, 원본 피클을 수정하지 않습니다.

## 재는 것
| 영역 | 지표 | 붕괴 신호 |
|---|---|---|
| 반복 | 꿈·또래 대화가 바로 앞 20개와 거의 같은 비율 (앞/뒤 절반) | 뒤 절반에서 늘어남 |
| 관심 흐름 | 상위 8개 관심 유지율, 회당 새 관심 수 | 유지↑+새 관심≈0 (정체) / 유지↓ (불안정) |
| 탐색 | 탐색 주제 다양성, 수집률 | 다양성이 크게 줄어듦 |
| 신념 구성 | 몰랑이 세계(또래·마을·꿈·여행)에서 생긴 사실 비율 | 최근 사실일수록 급증 (자기 강화) |
| 모순·격리 | 주별 모순 질문, 격리 사유 | 모순 질문이 계속 늘어남 |
| 사람 개입 | 사람 승인 사실·격리 판정·보낸 질문 / 100회 | 많을수록 "구조 덕인지 사람 덕인지" 구분 불가 (교란 변수) |
| 목적 | 핵심 목적 판 간 유사도, 근거 연결률, 핵심 수렴·다양성 | 근거 없는 목적, 갑작스러운 갈아엎기 |
| 두 시점 비교 | 페르소나·핵심 목적 유지, 사람 승인 기억 보존, 사실 보존율, **설명되지 않은 소실** | 사람 승인 기억이나 확신 기억이 창 밀림 없이 사라짐 |

두 시점 비교는 **기억 창 상한**(기본 1200, 예전 버전 400)을 함께 봅니다. 이후 시점의 사실 수가 상한에 닿았으면
사라진 사실을 "창 밀림 가능"으로 따로 분류해서, 기존 연속성 지표가 창 밀림을 소실로 세던 문제를 피합니다.

## 한계
- 문자 바이그램 유사도는 의미 유사도가 아닙니다. 다른 낱말로 같은 말을 반복하면 놓칩니다.
- 상한에서 잘린 목록은 남은 구간만 봅니다. 92번 기준 12개 목록 중 9개가 잘려 있습니다 (예: 상념은 최근 2.8일치).
  장기 관찰을 제대로 하려면 몰랑이 쪽에서 잘라 내기 전에 따로 보관(아카이브)해야 합니다.
- 신호 표시는 임시 기준입니다. 검증된 임계값이 아닙니다.
- 대화에서 기억을 실제로 꺼내 쓰는지(접근성)는 모델 호출이 필요해 재지 않습니다.
- 사람 개입과 구조의 효과를 분리하려면, 사람 앵커 없이 돌린 비교 실행이 따로 필요합니다.
