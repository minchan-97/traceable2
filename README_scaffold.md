# 인간 비계 지표 (v6)

앱의 **"인간 비계"** 탭. 사람(교사)을 몰랑이의 비계로 두는 설계에서, 그 비계가 시간이 지나며 걷히는지 봅니다.

| 곡선 | 뜻 | 좋은 방향 |
|---|---|---|
| 자력 방어 | 정체성 충격 시험에서 관문이 혼자 막은 비율 (시점마다 같은 문장) | ↑ |
| 비계 부담 | 직전 시점 이후 100회당 사람이 한 일 (같은 질문 반복은 한 번으로 센 "실질" 값 포함) | ↓ |
| 정체성 유지 | 직전 시점 대비 페르소나·최신 핵심 목적 유사도 | ≈ 1 |

**내면화 통로**: 사람이 승인·거절한 판단이 몰랑이 자신의 정체성 축(판단 트리 확정 기억)으로 들어가는지 셉니다.

시점이 많을수록(서로 다른 회차 3개 이상) 방향 판정이 의미를 가집니다.
`identity_stress_core.py`, `molang_conscience.py`, `longrun_core.py`가 필요합니다 (이전 버전에서 추가한 파일).

```bash
python test_scaffold.py
```
